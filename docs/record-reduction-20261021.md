# 每日记录：调整专注时长

本地实现，尚未发布。入口：每日记录 → 管理 → 记录右侧「⋯」→ 调整专注时长。

- 保留删除功能。仅已完成且至少 1 分钟的记录显示时长调整入口；2026-10-22 改为小时、分钟双滚轮，直接选择调整后的总时长，不提供秒数输入。
- 只允许减少，不接受增加、相同时长、负数和非整数秒；允许减到零并保留原记录。
- 保留记录 ID、项目、开始时间，从末尾实际专注区间截短，暂停不算作扣减时长。跨天的索引、统计、热力图与时间线同步重算。
- 保存使用原有提交恢复和同步队列。防重复点击、过期页面及切换账号写入；冲突重新提交时仍禁止增加。

## 弹窗与主题

弹窗使用主题页面底色和现有控件颜色。竖向面板最大 400px，较宽横屏最大 540px，滚轮与结果左右排列。展示项目、记录时间、原时长和调整后时长；打开时默认选中最接近原记录的可用整分钟，选项始终严格小于原时长，滚轮运动中不能提交。删除记录入口保留。

滚轮固定 132px 高，单项 44px。小时范围取当前记录可设置的整小时；分钟范围随所选小时动态限制。切换到最大小时时，超过上限的分钟自动收至可用范围。选中的小时和分钟就是保存后的最终记录时长；例如原记录 53分14秒，选择 48分钟后保存为 48分钟。短于1分钟的记录不显示调整入口。

正文使用有明确高度的原生滚动区，标题和操作按钮留在正文之外；横竖屏变化后重新测量，旧测量结果不能覆盖新布局。页面显式传递当前主题，root-portal 将弹窗放在页面根层，原记录页面保留在遮罩下。滚轮移除默认白色遮罩，使用主题色选中项和分隔线。
