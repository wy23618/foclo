# 登录、游客导入和入门体验

- 首次进入直接展示专注首页，可浏览功能并在本机使用，无需先处理登录选择或授权。专注页空闲时显示可关闭的轻量登录提示，也可从设置里的“账号与登录”主动进入。用户主动选择登录后，协议默认不勾选；主动勾选同意《用户服务协议》和《隐私政策》后才可连接微信，协议链接可单独查看，不会触发勾选或登录。每次重新打开登录入口均重新确认。登录不要求头像昵称，也不收集手机号；计时、暂停及休息期间不显示登录提示，演示页面也不显示。已有登录凭证继续复用，正在计时时不打断。
- 头像昵称是登录后设置中的可选资料，不再在启动时要求补充。真实身份由后端微信登录凭证确定；资料按实际账号在本机独立保存，头像复制为持久文件，失败保留旧资料。设置页显示头像昵称并允许修改。没有把用户填写的资料伪装成微信认证信息，手机号不收集。新设备需要重新选择展示资料。
- 登录成功后只询问一次“保存之前的记录？”，按钮为“一起保存 / 暂不保存”。用户确认前不会上传游客记录。
- 确认后自动整理，无逐项选择界面。账号内容优先：已保存的记录跳过，删除标记不恢复，已删除项目及其子项目的旧记录跳过。同一项目身份直接使用账号现有项目，同名且同一父项目自动归入已有项目；不同分类下重名的新项目自动加“登录前”后缀，保留原分类关系。
- 保留在本机的选择按微信账号和游客数据版本保存；相同资料不重复询问，账号页仍保留手动导入入口。导入成功后隐藏相同游客资料的导入入口。
- “账号与登录”只展示当前账号、保存状态、资料修改与退出。登录后不再重复展示“微信使用中”卡片。游客记录以“登录前的记录”展示，保存后隐藏。退出选择持久保存，下次打开不会自动重新登录；主动登录后恢复自动账号访问。手机号登录暂不实现。
- 专注页显示自动保存、离线暂存或需要处理的状态。计时期间不展示入口，沿用计时保护，避免切换账号打断专注。
- 欢迎页和指南共用三张滑动入门卡，补充技巧按需展开。
- “数据与备份”是日常备份和恢复的唯一操作页，主要入口为“保存一份备份 / 从备份找回记录”，另有项目管理。“其他操作”折叠统计表、偏好重置、清理与数据维护。账号页只提供到这里的导航，不再堆叠本机、账号、历史空间等多种导出。
- 数据维护使用账号页的独立维护模式（tools=1），隐藏账号和游客记录界面，保留异常排查文件、清理前记录找回、重新下载、账号清空与注销。修复文件不能当作日常备份，页面明确用途；原清理保护仍保留。
- 已移除游客处理中的项目位置选择、记录比较、另存一条、逐项确认等界面及代码。账号页只保留一个“保存之前的记录”入口；整理完成后隐藏该批记录入口。成功回执在本机持久保存，游客原副本仍保留，中断可重试相同任务。

验证：93 项前端测试通过；后端既有测试与新增自动整理测试通过，数据库测试验证重复任务回执、不同 ID 的相同记录去重、已删除记录不恢复、账号改名不覆盖和删除项目子树不恢复。游客整理前先完成当前账号待保存修改，避免尚未上传的删除操作被旧副本抢先导入。开发者工具确认旧逐项选择界面已移除。检查未提交真实用户记录合并。

发布配套：前后端必须一起更新。预览响应通过 KEEP_ACCOUNT 标识自动整理能力；旧服务器没有此标识时客户端拒绝提交，保留原记录，不退回旧合并流程。

迁移确认修复：微信原生弹窗按钮最多四个汉字，原“迁移到账号 / 保留在本机”各五个字，导致 showModal 直接失败而未开始导入。改为“迁移记录 / 留在本机”，并将弹窗原生错误转换为明确的可读错误。开发者工具已复现原错误并验证新弹窗正常打开；新增测试检查按钮限制、确认前不上传及弹窗失败不上传。同类“清空云端数据”按钮改为“确认清空”。

运行限制：正式版服务地址尚未配置。2026-10-12 已部署云端自动整理后端并验证健康状态、代码摘要和能力标识，见 cloud-guest-auto-deployment-20261012.md。没有公开发布小程序；手机实际游客导入及两台设备同步结果仍需真机确认。
