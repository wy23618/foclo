## 性能与容量

performance-results.json 是一次 Node 24.18.0 / Windows 基线：500 个项目、10,000 条完成记录、20,000 次暂停，统计净时长 15,000,000 秒。备份 JSON 7,843,479 字节；迁移规范事实 JSON 7,181,777 字节；事实与索引约 8,656,347 字节，升级两份额外副本约 17,312,694 字节。未计文件目录/键名/日志/历史视图开销。

该样本需分块迁移，不能通过 650 KiB 单次本地备份合并。文件层的 96 MiB 是应用预算，不是微信平台容量承诺；错误仍由底层真实返回。旧视图/游客副本不自动清理，耗尽前需要用户导出后制定清理策略。Node JSON stringify/parse/全范围统计约 42.04/25.25/36.46 ms，**不能转换成真机不卡顿的结论**。
