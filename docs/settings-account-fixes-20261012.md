# 设置与账号一致性修复

- 默认开发者工具与手机连接相同云端服务；首次切换需重新登录，旧电脑测试缓存与待上传更改隔离保留。
- 游客提示显示尚未保存的项目/记录数量，已保存、删除或重复事实不再触发确认。先使用同步后的本机账号副本比较，用户同意前不上传游客内容。
- 设置首页直接显示管理项目；数据与备份只保留备份与恢复。项目行和更多菜单明确显示颜色与简称，现有最多八字的简称编辑功能保留。
- 备份等待文件生成成功后显示发送提示；文件写入失败、取消发送和不支持分享均有明确反馈。用户需发送文件并自行留存，生成本机临时文件不宣称完成外部备份。
- 前端全部 98 项测试通过，包括旧缓存隔离、游客去重/删除判断、备份异步发送与失败反馈。此次修改为小程序端代码，未修改云端数据库。
