# 页面层级与取消操作检查

2026-10-28，根据“取消添加子项目不应退出原编辑”的反馈，检查页面、弹层和返回行为。主页面继续复用现有原生历史，短操作保留在当前页面；项目统计、单日记录和完整图表继续使用独立详情页。

## 本次修正

| 入口 | 返回或取消后的落点 |
| --- | --- |
| 项目编辑 → 添加子项目 | 返回同一份编辑草稿，恢复滚动位置；添加成功也返回原编辑 |
| 选择项目 → 添加／删除确认 | 返回选择列表，保留整理状态，第二次返回才关闭选择 |
| 统计 → 热力图 → 统计范围 | 先关范围选择，保留热力图月份、范围与底层图表 |
| 统计 → 自定义日期 | 关日期弹层，已应用的时间范围与项目不变 |
| 今日／单日／统计记录 → 调整时长 | 先关时长调整，保留日期与记录管理状态；保存中不会退出上下文 |
| 专注 → 自定义时长／极简显示 | 系统返回关闭当前操作，取消不应用时长 |
| 指南 → 功能预览 | 返回指南，保留选中的功能 |
| 项目统计间切换／记录进入项目统计 | 相同项目及筛选范围复用已有详情，避免重复堆页；不同范围保留独立详情 |

从编辑弹层进入统计时仍新开详情，返回后保留编辑上下文，不为减少层数而丢弃草稿。主导航不附加永久拦截；仅有弹层时接管返回。一个页面统一处理当前最上层操作，避免组件分别争抢返回。

2026-10-29：普通卡片不再隐藏底部主导航。项目选择、自定义时长、今日记录、欢迎卡片、日期范围、统计项目选择和热力图打开时，底部导航仍保留在原位；模态遮罩仍可使背景变暗、阻止穿透。极简显示、防误触、完整图表及全页身份入口仍隐藏主导航。

## 已核查并保留

- 自由调色的返回只回传草稿，集中保存后才改项目。
- 日期原生选择器、设置中的原生选项、账号确认与恢复面板的取消不提交操作，不退出所在页面。
- 图表大图、单日详情与项目统计保留完整内容；返回后沿用原项目、日期及筛选。
- 原主页面复用与导航失败回退逻辑保留。

自动化覆盖：`tests/project-workflow.test.js`、`tests/modal-navigation.test.js`、`tests/main-navigation.test.js` 及现有界面、演示、记录调整、平板回归。微信模拟器使用隔离示例验收；真机系统手势需在上传后的开发版本复验。

模拟器已复验：遮罩取消恢复原编辑草稿；连续三次返回分别回到原编辑、管理列表和专注页；子项目添加成功后返回未保存的父项草稿；从编辑查看统计后返回原草稿；取消专注时长不应用修改；记录调整只退到今日记录；热力图范围和日期弹层逐层取消；相同统计范围回到已有项目详情。修复了原生返回层重建产生额外关闭回调的问题，并补充回归。

复查补充：旧的独立项目选择页补接选择事件；列表重读或编辑已关闭时不压入子编辑返回状态；已有详情若还开着弹层，则保留其上下文而另开详情，不把用户直接送回一个未关闭的弹层。
