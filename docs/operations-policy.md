# 当前运行规则与正式上线默认方案

更新：2026-10-09。用户已将常规准备交由主执行处理。以下是当前实际规则和正式上线预案；没有购买或公开发布。

## 当前已采用并运行

- 开发服务仍可在自己的电脑运行；云端另有阿里云杭州ECS，Ubuntu 22.04、2核2GiB、40GiB。控制台显示按量付费、健康正常；后端与PostgreSQL已内部部署，API只绑定127.0.0.1:3000、数据库只绑定127.0.0.1:5432。用户确认没有域名；临时开发HTTPS已在公网开放80/443，手机开发预览扫码、微信登录和同步已通过。体验版/正式版仍不使用公网IP。
- 隐私说明入口在“设置 → 隐私与数据”。游客可继续本地计时；登录和游客合并分开。页面明确说明服务器用微信 OpenID 关联账号，不读取昵称/头像/手机号；列出同步的项目、专注/暂停记录、账号偏好（含默认/常用时长）及回执，并区分只留在本机的主题和显示偏好。服务日志会隐藏授权头、Cookie、微信 code、access token和refresh token；Nginx访问日志可能包括IP及含查询参数的URL，按日轮转最多14份，systemd日志限额100MiB/最多14天。未接广告或行为分析SDK。
- 注销POST仅登记申请，重复提交复用同一待处理ID；GET只查询自己的最新申请。账号页先查询，已有申请显示待处理。没有把提交申请当成删除成功，没有执行真实账号删除。
- 本机备份为AES-256-GCM加密，密钥用当前Windows用户的DPAPI保护，数据和密钥分开保存。后台每日检查一份成功备份，启动时补做当天缺失备份，运行期间北京时间20:00以后每5分钟检查；失败不标成功，继续重试。停止本机服务器同时停止该后台进程。
- 本机旧备份与恢复样本当前不自动删除，以保留联调证据。旧.dump仍是受限目录中的明文归档，新.dump.enc是加密归档。新方案不回写或自动移除旧资料。
- 云端开发数据现保存在阿里云杭州临时ECS。数据库加密备份存放在同一服务器；尚无异地备份与自动过期清理。隐私页面已写明这些实际边界，避免误以为注销申请会自动清除备份。
- Windows计划任务运行被系统策略拒绝，已移除这份新建的失败任务，改用本机服务器启动的普通当前用户备份进程。没有改系统策略或要求管理员口令。
