代码、迁移、证书部署、数据库和备份恢复我会继续准备。域名的注册实名信息必须是你的真实资料，ICP备案也需要真实主体资料；我不能代填或猜测。确定域名名称及实名主体后，可以按控制台当时显示的实际订单价继续；AppSecret、数据库密码等秘密不要发到聊天。
