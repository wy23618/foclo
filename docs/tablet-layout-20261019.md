## 行为

- 屏幕两个方向均至少 600px、当前窗口至少 600px 宽时启用平板布局。手机横屏也保留原布局；平板窄分屏退回原单列布局。使用物理屏幕尺寸判定，打开键盘不会切回随窗口宽度放大的尺寸。
- 专注页竖屏居中收窄，横屏左右排列表盘与操作区；矮横屏缩小表盘，操作区内容较多时可滚动。游客说明出现时为竖屏表盘另外分配空间。按钮、模式与时长选择保持适合触摸的尺寸。
- 统计页在宽屏分栏，筛选和总览占整行，分布与项目列表、每日柱图与时段图并排。没有项目列表时分布卡占整行。设置页按组分栏。
- 记录、账号、设置详情、项目管理、隐私和指南页限制阅读宽度。通用弹层居中并限制宽高，热力图正文使用有明确高度的滚动区域。
- 项目选择器高度计算使用实际底栏高度；旋转时刷新选择器、热力图手势宽度与 Canvas 表盘。自定义时长滚轮的选中框与选项高度一致。
- `app.json` 启用 iPad 的 `resizable`，保留各手机页面原来的旋转设置。配置依据见[腾讯官方小程序平台开发指南](https://staticintl.cloudcachetci.com/doc/pdf/product/pdf/tencent-cloud_1219_57657_en.pdf)。

## 手机样式保护与维护

原有 WXSS 保留在每个文件的 `tablet-generated:start` 标记之前。生成区仅在平板媒体条件下生效，将原来的 rpx 按 0.6px 的固定比例换算，避免宽屏无限放大。定制平板布局放在 `tablet-generated:end` 之后。内联树缩进、柱图高度在手机上仍回退到原始 rpx 值。

修改原始 WXSS 后运行：

```sh
node scripts/build-tablet-styles.js
node --test tests/*.test.js
```

生成器保留完整规则和原始先后顺序，包括百分比、零值重置、方向条件与动画，重复运行不会改变输出。`tests/fixtures/phone-style-contract.json` 保存本次修改前 29 份手机样式的指纹；未经明确的手机界面变更要求，不应更新这些指纹。
