# YoTick 云端费用估算

核对日期：2026-10-08。这里是预算依据和计算方法，不是购买报价。云服务价格会按地域、规格、带宽、折扣及账号权益变化；最终以登录后订单金额为准。本文件没有创建订单或资源。

## 目前的试用环境

阿里云控制台此前显示杭州 ECS、2核2GiB、40GiB，按量付费，参考用量约 **¥0.123/小时**。按30天720小时计算，试用抵扣用完后的计算与系统盘估算约 **¥88.56/月**（¥0.123 × 720）；这不是转包月价格，也不含超额公网流量或其他按量项目。

个人试用显示总额 **¥300**、单小时抵扣上限 **¥0.833**、有效期 **3个月**。如果实际小时用量保持¥0.123，¥300约可抵扣101.6天，但有效期仍以3个月为限，且其它用量可能提前消耗额度。中国内地公网流量每月20GB免费额度；超出后，CDT当前首档参考价为¥0.80/GB。例如月出网50GB，超出免费额度的30GB约¥24。实际计量和账单为准。

计算依据：[ECS免费试用额度与期限](https://help.aliyun.com/zh/ecs/user-guide/ecs-free-trial)、[CDT公网流量价格](https://help.aliyun.com/zh/cdt/internet-data-transfers/)、[ECS按流量计费说明](https://help.aliyun.com/zh/ecs/public-bandwidth/)。控制台观察到的¥0.123/小时不是对未来续费或包月价格的承诺。

## 低用量正式环境预算

| 成本项 | YoTick 当前设计 | 预算计算方式 | 现在是否有准确报价 |
| --- | --- | --- | --- |
| ECS 与系统盘 | 同一台杭州 ECS 运行 Node 后端和 PostgreSQL | 包年包月转换订单总价；或在继续按量时用实际小时账单×运行小时 | 否。当前¥0.123/小时仅为账号页面观察值；ICP备案要求需用符合条件的包年包月资源 |
| PostgreSQL | 自行维护并与 API 共用 ECS | 不另收托管数据库服务费；数据库容量、I/O、备份占用同机资源 | 服务器订单确定后可知；当前不应把它算作独立RDS费用 |
| 公网接入/网关 | Nginx 或 Caddy 代理到本机API | 软件本身无许可费；公网带宽或流量按 ECS 所选计费方式另算 | 未配置。备案资源要求还需公网带宽 |
| 公网流量 | 微信 API 请求与响应从 ECS 出网 | 月出网GB超出当月免费额度后，参考公式 `(出网GB - 20) × ¥0.80`；低于20GB按CDT规则不产生该档流量费 | 价格随阶梯和地域变化；按实际用量账单 |
| 域名 | 目前没有域名 | 按所选后缀的注册价及次年续费价核算 | 否。需选定域名后看注册/续费订单 |
| HTTPS证书 | 域名准备后部署 | 可选可自动续期的免费公开DV证书；阿里云个人测试证书虽免费但有效期90天且官方提示OCSP稳定性有限，只用于测试，不作为生产保障 | 免费证书可以申请，但可用性和续期要验；付费证书价格按所选产品 |
| 日志 | 目前journald本机限额保存 | 不产生独立日志服务账单；若启用SLS等托管日志，按采集量与保留期计算 | 托管日志未配置 |
| 备份 | ECS内每日加密备份，另有手工复制的电脑副本 | 同机本地备份不增加独立云服务费；持续异地备份需要对象存储/另一故障域，按存储容量、请求和读取流量计费 | 异地自动备份尚未配置，不能按零成本宣称已覆盖 |
| 监控告警 | 当前有本机健康检查，没有外部接收告警 | 本机定时器不另收费；外部告警产品和短信按选定方式计算 | 未配置 |

以现有实例转包年包月来满足备案资源条件时，阿里云当前说明要求中国内地节点、包年包月购买时长**超过3个月（续费累计可计入）**并购买公网带宽；当前按量免费试用不满足该条件。必须在控制台转包月订单页确认实例、云盘、带宽和实际优惠总价；未核价前不购买。[备案服务器要求](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/overview)。

证书价格依据：[阿里云个人测试证书说明](https://help.aliyun.com/zh/ssl-certificate/purchase-an-individual-test-certificate)、[Let's Encrypt免费公开证书说明](https://letsencrypt.org/about/)。异地备份成本构成：[OSS计费概览](https://help.aliyun.com/zh/oss/billing-overview)、[OSS流量费用](https://help.aliyun.com/zh/oss/traffic-fees)。

## 用量增长时如何扩预算

不按猜测的“用户数”承诺容量。先记录每月数据库体积、加密备份总量、API出网流量、CPU/内存峰值、请求延迟和磁盘剩余，再决定是否拆分数据库或升级实例。增长后的月费按“ECS新规格订单 + 带宽/出网 + 异地备份存储/请求 + 托管日志/告警（如启用）+ 域名续费”逐项相加。现有DevTools大样本只是本地文件层性能测试，不能据此估算线上用户数或云端费用。

## 当前结论

- 免费试用足以继续内部开发和检查服务；¥300是有限额度，不是永久免费服务器。
- 当前控制台观察值推算，额度耗尽后的持续按量运行约¥89/30天，再加超出免费部分的公网流量及后来选用的服务。
- 备案可用的包月总价、域名注册/续费价格和异地备份具体价格目前都没有最终数字；需要先有域名选项，并在阿里云订单页查看具体规格与时长。
- 公共DV TLS证书可做到零证书费，但服务器、域名、带宽、备份和运维费用仍需分别计算。
