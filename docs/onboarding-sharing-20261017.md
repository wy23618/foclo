# 首次登录、游客提示与分享

- 首次进入的登录入口补齐服务协议与隐私政策勾选。默认未同意，登录按钮置灰，点击处理函数也检查同意状态，通过后才调用账号登录。查看协议不会关闭登录入口或代为勾选。
- 游客可直接体验。专注页空闲时显示轻量提示卡：“先安心专注，随时都能登录”，说明本机保存范围和以后从设置登录的路径，并提供微信登录与关闭按钮。关闭后当前页面实例不再提示；重新进入小程序后可以再次显示。登录后刷新移除提示，计时、暂停、休息及演示时不展示。
- 专注、统计、设置三个主页面添加转发回调，统一进入 `/pages/focus/focus`，链接不携带账号、项目或演示参数。聊天卡片使用固定封面 `/assets/share/foclo-cover.jpg`（1000 × 800，森绿色 F 标志与「把专注留给自己」），避免默认截取页面中的个人记录。不添加朋友圈入口。

验证：前端 133 项测试通过。新增行为测试覆盖未同意不认证、同意后认证、游客选择不认证、再次进入重置勾选、协议查看不代为勾选、计时与休息保护及分享入口参数。微信真机视觉效果、右上角分享菜单与正式版登录需在开发者工具及真机进一步验收；未上传或发布小程序。
