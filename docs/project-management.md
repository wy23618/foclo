# 项目选择与管理交互

2026-10-28：保留专注页的胶囊入口，重构展开卡片与项目管理页。

- 选择卡片直接显示项目，不再重复展示最近使用。按是否有下级决定点击行为：有下级展开或收起，没有下级则选中并收起卡片，计时仍需主动开始。
- 父项使用文件夹标识、更明显的字重和下级数量，最上层分类间增加留白；叶子项目使用小圆点和较轻的文字，逐层缩进。管理页使用同样的父子区分，不只依赖颜色。
- 两处项目名称保留轻微下压与透明度反馈，松手立即恢复，不再闪绿色底色。按钮使用同样的即时反馈；已选项目的静态底色和勾选标记保留。
- 选择卡片和编辑弹层使用约 200ms 入场、140ms 退场；箭头转动与子项出现提示展开层级。添加子项目向前轻移，返回原编辑反向轻移，保留原草稿和滚动位置。逻辑关闭和返回立即执行，退场仅保留绘制层；快速重新打开会取消旧的退场清理。尊重系统减少动态效果设置。
- “整理”切换就地增删。整理时点名称只展开或收起，不触发选择；每项右侧可添加子项目或删除。删除确认展示受影响的项目数与记录数。
- 添加、删除确认各自替换卡片内容，不在列表中插入表单。添加可选择任意在用父项；完成或取消后恢复列表位置与整理状态。
- 管理页直接新建项目。点名称或“编辑”进入集中编辑；名称、颜色、简称由 `updateProjectDetails` 一次校验并提交，沿用现有 `project.patch` 同步协议。
- 从编辑中添加子项目会保存上一层草稿、调色展开状态和滚动位置。取消、遮罩、关闭及系统返回均只退一层；添加成功也返回原编辑。子项目实际创建，父项的其他草稿仍需单独保存。编辑已有项目不会清空列表搜索。
- 自由调色从集中编辑进入时只回传草稿，点击集中编辑的“保存修改”后才写入。原独立颜色页面仍可直接保存。
- 所属路径在已有项目编辑中用于定位；新建时可选归属。已有项目的跨父项移动不在现有同步协议中，本次不改变其父子关系。
- 排序须显式进入“排序”，再长按手柄调整同级顺序；正常滚动不会启动拖动。搜索、归档、恢复、专注统计和原自由调色均保留。
