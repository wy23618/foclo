# 平板横屏专用 UI（2026-10-21）

> 2026-10-22 已继续调整横竖屏与不同比例适配，当前规则和验证见 [平板不同比例适配](tablet-proportions-20261022.md)。本文保留首次横屏调整记录。

本次把横屏改为独立工作区。手机、平板竖屏及窄分屏继续使用修改前的界面。代码未上传或发布，微信平板真机验收尚待完成。

## 主要变化

- 主导航在平板横屏下变为左侧窄导航栏，与内容标题顶部对齐。内容区独立留位，统一页边距，不再预留手机底部导航高度。
- 专注页改为一张完整的主卡片，表盘与操作区共用外边界，中间用细分隔线和浅底色分区。项目、表盘和操作区按窗口高度缩放、居中。操作区集中放置时长、模式、开始/暂停/继续、极简、防误触和今日累计；保留今日明细入口。说明较多时，操作区内部可滚动。
- 统计页改为横向筛选栏、通栏总览、并排分布图与每日趋势图、通栏时段图、项目明细。总时长和三个指标共用一条基线，消除小总览卡下方的空洞。项目统计和当天统计共用总览样式。图表设置最大阅读宽度，无记录时缩小空状态；每日柱图只在有数据的平板横屏下使用适配的高度。
- 设置页改为顶部横向账号栏，下方两列设置组；左列为专注设置和数据管理，右列为界面偏好和帮助信息。两列都包含四行设置，顶部、底部与行高对齐，避免短分组和长分组共用网格行造成空洞。
- 项目选择器和热力图取消横屏底部导航的空白保留，旋转后重新测量尺寸。

## 视觉层级

横屏以表盘、主要操作、辅助信息三个层级组织。实色主按钮承担主要视觉强调；时长选中态使用浅绿底与细描边，模式选中态使用白色浮层，避免多个深绿块争夺注意力。字号、圆角和留白按页面、卡片、控件分层，时长数字使用等宽数字排版。日期切换保持 44px 触摸区域，与筛选控件的尺寸一致。这些调整仅作用于横屏工作区。

## 竖屏保护

`themes/landscape.wxss` 和各页新增样式只在窗口至少 900px 宽、设备短边至少 600px、横屏条件满足时生效。页面上的 `landscapeLayout` 还会检查物理屏幕方向和原生旋转事件，避免竖屏弹出键盘后因窗口变矮而触发横屏 UI。新标题、导航品牌和专注面板信息在原布局中隐藏，不占空间。专注、设置和统计的共用内容通过 WXML include 复用，横屏条件分支只增加横屏需要的容器；手机、竖屏保持原有原生视图层级和内容顺序。

`withLandscapeLayout` 只包装六个页面的加载、显示和窗口变化事件，保留原生命周期的参数、返回值及异步结果，不更改计时、数据读取或导航行为。页面从后台返回时重新读取方向，不沿用离开前的方向。

新增样式位于平板生成区之后；修改原始手机 WXSS 时继续运行 `node scripts/build-tablet-styles.js`。手机样式保护指纹保持不变。

## 验证

- `node --test tests/*.test.js`：144 项通过。
- 六个页面在 14 个尺寸下共 84 组浏览器排版检查，其中 54 组手机/竖屏与本次修改前的截图、元素位置、尺寸、字体和间距对照一致。
- 对专注中、暂停、游客提示、自定义时长及六行月份热力图检查边界，确认操作区和弹窗可达。
- 额外检查竖屏弹出键盘时六个页面的布局；自动化用例同时覆盖方向判定、窄分屏、返回页面及生命周期返回值。
- 补充 30 组视觉场景：1024×768、960×600、1366×1024 下，有数据、无数据、当天统计的明暗主题，以及专注、设置、项目统计和当天统计的深色主题。有数据图表使用现有布局与绘图代码绘制样例。
- 检查使用真实 WXML/WXSS、样例数据和独立组件样式。原生组件以浏览器替代呈现，不能代替微信渲染、触摸和滚动验收。

真机重点确认左右手触摸左侧导航和操作面板的手感，旋转时计时连续，项目选择/滚轮/日历弹层尺寸正确，以及竖屏和手机原界面保持一致。
