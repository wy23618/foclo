## 连续验收流程

1. A 游客空间开始、暂停、恢复、结束，退出进程重开，核对净时长/暂停/统计；没有云配置时仍可本地使用。设置备份副本。
2. A 真实 wx.login 登录：先验证没有隐式合并游客数据，明确预览并确认迁移。B 同账号登录后核对 ID、父子层级、项目颜色、每条暂停与时长；B 使用另一账号验证互不可见。
3. A 断网修改项目及完成记录，重启后再联网；B 读取最终结果。服务端提交后由测试网关丢一次上传响应，核对原操作 ID 的回执重试、完成记录仅一次。
4. A/B 并发改名/改色/排序/归档，检查整组冲突；分别选择本地/云端。离线选择已有云端版本后重启，核对可恢复选择与恢复副本，没有未上传资料被丢弃。
5. A 离线、B 删除记录/项目：A 正在计时则继续计时和保存完成事实；重连后不能复活删除 ID，使用恢复中心显式归属/新 ID 保存资料。导出并核对保全副本。
6. 活动专注/休息拒绝切换；慢登录准备期间开始计时仍拒绝切换。退出/登录另一账号后，旧延迟响应和旧页面命令不改新空间。访问/刷新令牌过期时队列保留，重新登录后恢复。
7. 迁移逐页断网、关闭进程和重复上传后续传；同名不同 ID、同 ID 不同内容必须显示明确选择。原游客及上次映射仍可保全；再次迁移包含后来新增游客资料。
8. 用隔离测试库演练备份恢复并更换 restore_epoch。A 有待上传资料时进行全量恢复，分页中继续计时；构建期间本地变化不得被旧指针覆盖。核对截止点后的增量和历史视图导出。
9. 在已备份并获准的测试账号清空：B 旧代次返回必须隔离，不能回灌。清缓存应拒绝有待上传/冲突状态，不能当作账号清空。注销申请只显示待处理，行政删除遵循正式流程。
10. 用 500 项目/10,000 记录/典型暂停测量：文件剩余空间、升级副本开销、冷启动、开始/暂停/恢复/结束持久化延迟、后台同步时同操作延迟、统计耗时与帧表现。记录多次测量的中位数/高分位、测量方法和异常；不以 Node 基线替代真机结果。
